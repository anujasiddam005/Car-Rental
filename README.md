🚗 Car Rental Website

A full-stack Car Rental web application built using React.js, Node.js, Express.js, and MongoDB. The application aims to provide a convenient platform for users to explore cars and manage the car rental process.

✨ Features

🚘 Browse available cars

🔍 View car details

🔐 User registration and login

👤 User and owner roles

🚗 Manage car listings for owners

📅 Car booking functionality

📱 Responsive user interface

🎨 Modern UI with Tailwind CSS

⚡ Smooth animations using Framer Motion

🔔 Toast notifications

🛠️ Tech Stack

Frontend

React.js

Vite

Tailwind CSS

React Router DOM

Axios

Framer Motion

Backend

Node.js

Express.js

MongoDB

Mongoose

JWT Authentication
